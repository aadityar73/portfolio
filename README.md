# Portfolio

My personal portfolio site, live at **[aaditya-raikar.vercel.app](https://aaditya-raikar.vercel.app)**.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com) as a static site. No UI framework; the few interactive bits are plain JavaScript.

## Running it

Requires Node.js 22.23.4 or newer (`.nvmrc` pins 24).

```sh
npm install      # first time only
npm run dev      # local preview at http://localhost:4321
npm run build    # production build into dist/
npm run preview  # serve the built dist/ locally
```
